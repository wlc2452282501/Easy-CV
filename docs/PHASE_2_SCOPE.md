# 第 2 阶段范围说明

## 首期 OpenCV 算子清单

首期节点以“单张图像输入、单张图像输出”为主，所有节点都应保存参数，并提供参数对应的 OpenCV 代码片段和节点结果预览。

| 类别 | 首期节点 |
| --- | --- |
| 输入输出 | 读取图像、保存图像、摄像头/视频帧输入 |
| 几何变换 | 缩放、裁剪、旋转、翻转 |
| 色彩处理 | BGR/RGB、灰度、HSV、通道拆分与合并 |
| 平滑与增强 | 均值滤波、高斯滤波、中值滤波、直方图均衡化 |
| 二值与边缘 | 固定阈值、自适应阈值、Canny 边缘 |
| 形态学 | 腐蚀、膨胀、开运算、闭运算 |
| 形状分析 | 轮廓查找、轮廓绘制、面积/周长、外接矩形 |
| 人脸检测 | Haar/LBP Cascade 检测框，检测参数可调 |
| 可视化 | 检测框、文字、关键点或轮廓叠加 |

节点注册表应保留扩展点，后续可以加入更多 OpenCV 模块，而不修改流程执行器的核心逻辑。

## 人脸检测与人脸身份识别

- **人脸检测**：判断图像中的人脸位置，输出矩形框或关键点；它回答“哪里有人脸”。首期只需要 OpenCV 检测器和对应的分类器模型文件。
- **人脸身份识别**：将检测到的人脸与已登记人员或身份类别进行匹配；它回答“是谁”。这需要识别算法或 embedding 模型、登记数据集、距离/阈值策略和数据管理方式。

当前项目只实现人脸检测，不自行假设身份识别方案。开始身份识别实现前需要确认：

1. 使用 LBPH、Eigen/Fisher，还是基于 DNN 的人脸 embedding。
2. 模型文件来源和版本，是否允许随项目分发。
3. 登记数据集的目录/标签格式，以及是否需要在界面中管理人员样本。
4. 识别阈值、误识别处理和结果展示方式。

## 节点执行约定

- 节点输入输出类型、图像尺寸和通道数必须明确；不兼容时返回可读错误，不静默转换。
- 预览使用当前节点的输出，完整流程使用拓扑排序后的节点序列。
- 代码查看器展示等价的 OpenCV C++ 片段，运行时仍由统一的节点执行器调用算子。
- 读取摄像头或视频时，预览刷新与节点参数更新需要可控，避免在 UI 线程中执行长时间阻塞操作。
